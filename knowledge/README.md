# Softy Knowledge Base

Persistent knowledge for the Softy policy. A new session should read files in this order:

## Quick Orient (30 seconds)
1. `tactics/priorities.md` — what to work on next
2. `experiments/failed.md` — what NOT to try
3. `strategy/current-approach.md` — active strategy

## Deep Context (5 minutes)
4. `mechanics/scoring.md` — how VOR is calculated (network-connected only!)
5. `mechanics/clips-behavior.md` — enemy timing + cascade failure risk
6. `strategy/network-expansion.md` — network connectivity analysis
7. `experiments/hypotheses.md` — untested improvement ideas

## Full Reference
8. `mechanics/game-rules.md` — complete rules table
9. `mechanics/energy-hp-model.md` — energy/HP math
10. `mechanics/roles-and-gear.md` — role stats and costs
11. `strategy/competitor-analysis.md` — gap to top
12. `experiments/log.md` — full experiment history
13. `experiments/successful.md` — changes that worked

## File Size Targets
- mechanics: 50-100 lines (factual, dense, from source)
- strategy: 100-200 lines (analysis + rationale)
- experiments/log: unlimited (append-only)
- tactics: 20-50 lines (current state, overwritten each session)
