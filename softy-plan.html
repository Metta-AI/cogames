Softy Policy Strategy plan for the Alignment League beta-cvc season

April 13, 2026 — Softmax / Maxwell Starr

This is safe. A policy is just a player — it receives observations and returns move commands. It cannot modify the game engine, scoring, maps, or other players' submissions. Policies run in sandboxed containers on the tournament server.

Context

Softy:v1 was uploaded as a starter policy and scores ~0.19 VOR. The leaderboard top is dinky:v27 at 27.40. After a deep analysis of the game engine source code, scoring mechanics, and the most advanced scripted policies in the codebase, this plan describes a rewrite of Softy as a smart, coordinated, multi-role agent.

Key insight: Reward = junctions_held / max_steps per tick over 10,000 steps. A junction captured at tick 100 earns 99% of its max value. Speed of territory acquisition is everything.

Architecture

Single file: ~/cogames/softy.py (~800–1200 lines)

  • SoftyCoordinator — shared team state (hub position, stations, junctions, extractors, agent targets)
  • SoftyState — per-agent persistent state (position, occupancy map, phase, retry count)
  • SoftyAgentImpl — per-agent decision logic with role-specific methods
  • SoftyPolicy — entry point, creates coordinator and assigns roles

3 miners sustain heart production. 2 scramblers counter clips' every-200-tick expansion. 2 aligners capture junctions fast. 1 scout finds everything.

Role Strategies

Miner Agents 0, 1, 4

  1. Navigate to miner gear station → acquire gear (+40 cargo, 10× extraction)
  2. Mine preferred extractor (diversified by agent)
  3. Extract until cargo full or HP low
  4. Deposit at nearest cogs-aligned building
  5. Repeat; HP check: return to heal if steps-to-safety > HP−10

Scrambler Agents 2, 5

  1. Rush scrambler gear station (+200 HP)
  2. Get heart from hub
  3. Find nearest clips junction → scramble it
  4. Report to coordinator (now neutral for aligners)
  5. Return for another heart; 300 HP total allows deep pushes

Aligner Agents 3, 6

  1. Rush aligner gear station
  2. Get heart from hub
  3. Find nearest neutral junction within 15 cells of team network
  4. Align it → report to coordinator
  5. Target deconfliction: coordinator assigns different junctions to each aligner

Scout Agent 7

  1. Rush scout gear (+100 energy, +400 HP)
  2. Frontier-based exploration (BFS to unknown cells)
  3. Report all discoveries to coordinator
  4. After ~2000 ticks, switch to junction patrol

Navigation

  • Position tracking: Start at (100,100) on 200×200 internal grid. Update from last_action each step.
  • BFS pathfinding: On occupancy grid. Unknown cells = traversable (optimistic). Agent positions = temporary obstacles.
  • Stuck detection: Track last 4 positions. If oscillating, force random cardinal direction. After 10 stuck ticks, reset target.

Observation Parsing

Each step, parse the 13×13 token observation window:

  • Tags → identify hub, junctions, extractors, gear stations, walls, agents, team affiliation
  • Inventory → energy, HP, heart, carbon, oxygen, germanium, silicon, role gear
  • Globals → episode progress, last action, position offsets
  • Coordinator update → register any newly visible structures in shared team state

Implementation Steps

  1. Scaffold + obs parsing — classes, token parsing, position tracking
  2. Navigation — BFS, explore fallback, stuck detection
  3. Miner role — gear → mine → deposit cycle with HP awareness
  4. Scrambler + Aligner — gear → heart → scramble/align with target deconfliction
  5. Scout role — frontier exploration + discovery reporting + patrol
  6. Integration — coordinator wiring, deconfliction, junction tracking
